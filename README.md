# Smart Eco Yurt

Mobile app prototype for monitoring a smart eco yurt: indoor climate, air quality, and water systems. All sensor readings are **mock data**.

## Quick start

**Requirements:** Node.js 18+

```bash
npm install
npm start
```

When the dev server starts:

- Scan the QR code with **Expo Go** (phone on the same Wi‑Fi), or
- Press **w** to open in a browser, or
- Press **a** / **i** for Android / iOS emulator

## Usage

The app has four tabs:

| Tab | What it shows |
|-----|---------------|
| **Dashboard** | Overview of climate, air, and water metrics |
| **Climate** | Temperature, humidity, ventilation and heater controls |
| **Air** | CO₂ and VOC levels with air-quality alerts |
| **Water** | Tank level, flow rate, daily use, and grey-water reuse |

Pull down on any screen to refresh. On **Climate**, use switches to toggle ventilation and heating. No login or setup required.
